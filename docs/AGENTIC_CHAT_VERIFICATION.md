## User flow

The Linus Home/details design remains. Home conversation works before opening a file. Browser messages post only to `/api/chat`; routing selects conversation, basic technical, advanced technical, rendering, or UI. The original message reaches the selected worker unchanged. Technical workers inspect original source images/native records and retain citation/calculation validation and answer support review, without sufficiency preflight or intent rewriting. Conversation and both technical workers share the same validated UI capability. UI navigation never implicitly generates geometry. Explicit Stop and validated chat interruption target existing jobs.

Point, stroke, and explicitly entered linear measurements can attach to chat and rendering. Source marks remain normalized to original pages. Model points use individually pinned object-local anchors, including strokes spanning different storeys. Drawing marks/values remain user-provided. Multiple compatible measurements share a floor calibration; conflicting scales request a choice. Old-revision marks detach visibly instead of silently moving to a replacement. Originals and portable IFC evidence are unchanged by marking.

## Retained limits

Marks are building-scoped filesystem sidecars, not portable IFC annotation exports. Explicit source-floor measurements calibrate generation; a model mark is a user reference and does not automatically reshape native IFC geometry. Unsaved selected measurements can support explicitly attributed QA, while generalized arithmetic over user marks has no new calculation schema. Old marks remain pinned and may need reselecting/redrawing after a revision replacement. Existing accepted file formats, upload/IFC safeguards, original-source provenance, shared-workspace access rules, and schematic assumptions remain.

The render loop intentionally may continue spending provider calls until interrupted if the reviewers never agree. Stop, shutdown/restart, and concurrent revision interruption retain original sources and the last usable published model. No automatic provider fallback or cost top-up was added.
