# Reviewed implementation contract — drawing-derived IFC

The user's multifloor request supersedes the single-page extraction restriction. Root owns the contract. No model-generated code or IFC text is executed.

## Source and display transforms
Every model coordinate is normalized against the ORIGINAL displayed page, never a crop. For page aspect a=width/height, use P(u,v)=(a*u,-v). This handles nonsquare pixels correctly. A supported source segment of length L metres gives factor L / distance(P(start),P(end)); never compute calibration using uncorrected normalized coordinates. Source bboxes/vertices are never overwritten by model/display transforms.

Floor rotation is a display normalization around its source-region center (positive counterclockwise in world XY), inferred from source orientation and recorded. Floor order needs a visible label/basis; unknown order remains null, with source-diagram order used only for display. Common registration needs an explicit source anchor and evidence; otherwise use a declared schematic arrangement. Unknown storey elevation is not populated as a measured value. Viewer explosion is a display-only transform; it never changes stored IFC/source geometry.

Unknown floors normalize their largest panel extent to 10 display units for visibility. This is our visualization convention, not a measured length. All project coordinates are declared UNSCALED_DISPLAY_UNIT (IfcContextDependentUnit LENGTHUNIT) whenever any floor lacks calibration. Only all-calibrated projects use metres, and display-only heights/thicknesses still carry assumptions. Mixed-scale floor comparisons are not physical measurements. Per-floor calibration, transforms, orientation/order evidence and layout assumptions persist in the manifest.

## Building description
Schema source of truth is app/building.py: BuildingDescription(floors,limitations), FloorDescription(label,source,order,order_basis,rotation_degrees,orientation_basis,calibration,alignment,measurements,rooms,openings). PageRegion(page,bbox). Rooms carry label, polygon in original coordinates, basis observed|inferred, note. Openings carry kind door|window, label, original segment, source region, host_room (1-based), host_edge (0-based), basis and note. Invalid/ambiguous hosts are omitted with warnings, never attached arbitrarily. Measurements explicitly record observed/unknown, value/unit when present and source region; calibration uses a cited physical length and original segment. Alignment uses a cited source anchor and shared group; no inferred registration from matching outlines alone.

On the model wire points use named `x`/`y` fields and regions named `left`/`top`/`right`/`bottom`; internal canonical coordinates remain arrays. Gemini reconstruction uses medium reasoning following a controlled live quality comparison; existing response budgets and answer/gate settings remain unchanged.

Process ALL uploaded source pages, including multiple diagram regions per page. No new floor/room/vertex count caps: remove old extraction30/40 limits. Retain original upload10MiB/5pages/40MP/4096edge and IFC25MiB/4000elements/1milliontriangles safeguards. These can reject large inputs and artifact expansion from embedded source PNGs; no silent truncation. The existing answer100citations/4000highlights and generation token budget bound responses, not model coverage. Explain output incompleteness rather than deriving factual counts from generated inventory.

Strict finite coordinates, page bounds, valid polygons and nonzero dimensions are necessary geometry checks, not sampling limits. Per-floor invalid geometry is omitted transparently; overlapping-room conflicts are detected before filtering. Separate-floor polygons may overlap on different pages without conflict. Preserve a floor record even if no room survives, with a warning; reject only if the entire building has no renderable rooms.

## Identity, persistence and trust
Generate artifact namespace once from originating document.id; persist it as artifact_id. UUID5/artifact namespace + stable floor/room/opening indices produces compressed IFC GlobalIds. Keep those IDs on reopening under a fresh document.id. Stable indices survive partial omission.

Generator owns app/ifc_generate.py only: generate_ifc(description, document) -> bytes. It constructs IFC4 using IfcOpenShell entities, project/building/storeys/spaces/walls/opening voids/fills. Embed a versioned manifest under Pset_BlueprintQA on IfcProject plus per-element provenance. Source page PNGs, hashes and dimensions are embedded in the manifest; scene metadata, source references, observations and assumptions survive. No runtime network paths or filesystem paths in the artifact. Source images are the exact normalized original previews, never renders.

Root owns app/ifc_artifact.py: recognize generated markers BEFORE native catalog construction; validate version, source hashes/PNG bounds, source refs, manifest and IFC identity; restore pages and scene provenance, then tessellate actual IFC geometry. Recognizable own markers with missing/inconsistent provenance reject; no fallback to native IFC. Detection includes own project marker/property set or UNSCALED_DISPLAY_UNIT. Fully stripped/forged metadata cannot authenticate arbitrary third-party IFC; do not claim it can.

Both direct import_ifc and DocumentStore route recognized derived artifacts through the derived importer. Freshly uploaded generated IFC becomes document.kind=drawing with restored original pages and scene.source_kind=image, derived=true, catalog_complete=false, geometry_origin=inferred. It MUST NOT enter native deterministic count or property-evidence paths. Generated properties, dimensions and floor inventories are association hints only. QA receives original source pixels; it never receives embedded IFC quantities as factual evidence.

## Scene / UI / API
Extend Scene with derived:bool, artifact_id, floors:list[SceneFloor], ifc_url, layout. SceneFloor fields: id,label,source,order,scale_status,rotation_degrees,alignment_status,observations,assumptions. SceneElement gains evidence_basis and note; storey_id is its floor GlobalId. Scene.units remains relative|m but badges also inspect derived and per-floor scale. Generated room meshes are floor plates and visible by default; native enclosed space volumes retain their existing behavior.

POST /api/documents/{id}/scene generates the whole document; legacy page argument may be accepted but cannot restrict extraction. Cache once. GET /api/documents/{id}/model.ifc downloads cached bytes. Public document/scene exposes download URL. Reopened artifacts expose both original pages and the same IFC download.

Viewer adds floor filter, source-linked floor labels and independent exploded display toggle, plus derived IFC download. Multifloor schematic derived scenes default to separated display. Highlighting/assumptions remain separate. Evidence on a hidden floor reveals it. Source clicks use original page/bbox even after rotation, layout, export and reopening. Image highlight validation uses the correct source page/region and exact normalized label, never generated dimensions; uncertain mapping keeps evidence and leaves highlights empty.
