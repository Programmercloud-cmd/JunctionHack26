# Screenshot credits

These screenshots show Concrete's actual interface with public CubiCasa5K examples. The drawing and model views use `colorful-3181.png`; the Buildings list includes other public CubiCasa examples. No private uploads or conversations are shown, and no model inference was run to capture the gallery. The model is a saved schematic interpretation; Concept materials and furnishings are display choices, not original drawing evidence.

The Concrete application code is covered by the repository's [MIT license](../../LICENSE). The CubiCasa5K drawings and their derived content in these screenshots retain their dataset license: **CC BY-NC-SA 4.0**, non-commercial use only.
