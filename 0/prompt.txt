**Where Gemini and Blender fit**

Gemini makes sense as the language and visual interpretation layer: understand the question, select relevant evidence, interpret labels, and produce a structured query or extraction. Its API supports both [PDF understanding](https://ai.google.dev/gemini-api/docs/document-processing) and [structured outputs](https://ai.google.dev/gemini-api/docs/structured-output).

I would have code perform counts and measurements over extracted objects whenever possible. Each answer should retain the selected object IDs and source locations. That gives you reusable evidence and reduces repeated model calls.

For IFC, [IfcOpenShell](https://docs.ifcopenshell.org/ifcopenshell-python/geometry_processing.html) provides a route to processing existing geometry. Preserve element identifiers through conversion so selecting an answer can highlight the same elements in the viewer.
